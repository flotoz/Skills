# Fact-Check Protocol

Finance rules change every year (finance law, social security law, regulated
savings rates every 6 months). The model's memory is often one law behind:
e.g. the French flat tax (PFU) moved from 30 % to 31.4 % on 2026-01-01 when
social contributions on most capital income rose from 17.2 % to 18.6 %.

**Rule: never state a volatile figure from memory.**

## Volatile facts (always check)

| Fact                                                                      | Official source                                                    |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Flat tax (PFU) rate and its split (income tax / social contributions)     | service-public.fr, impots.gouv.fr                                  |
| Social contributions per envelope (PEA, life insurance, CTO, real estate) | service-public.fr, impots.gouv.fr                                  |
| Livret A, LDDS, LEP rates and ceilings; LEP income eligibility            | service-public.fr, banque-france.fr                                |
| PEA / PEA-PME contribution ceilings, early-withdrawal rules               | service-public.fr                                                  |
| Life insurance allowances after 8 years                                   | service-public.fr, impots.gouv.fr                                  |
| PER deduction ceilings, income tax brackets                               | impots.gouv.fr                                                     |
| Index country / sector weights (MSCI, FTSE, S&P)                          | index provider factsheet (msci.com, ftserussell.com, spglobal.com) |
| An ETF's fees, index, PEA eligibility                                     | issuer's factsheet / KID (amundi, ishares, bnpparibas-am…)         |

Stable principles need no check (PEA tax advantage after 5 years, life
insurance after 8 years, diversification, compound interest).

## Procedure

1. List the volatile figures the answer needs. Prefer fewer: a regime name
   often suffices ("flat tax on CTO gains").
2. If a web search / fetch tool is available, check each figure on an official
   source above (not a blog or forum). Use the current year in the query.
3. Open the page (fetch) before citing it; a search snippet is not a source.
   Cite inline: `PFU 31.4 % ([service-public.fr](…), checked 2026-10-18)`.
4. If no web tool is available or sources disagree: give no number. Name the
   regime, say the rate must be checked, and link the official page.
5. Figures from Finary data (balances, fees on holdings) are facts about the
   user, not volatile rules: no web check needed.
